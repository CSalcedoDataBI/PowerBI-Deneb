# Diverging Stacked Bar Chart (Population Pyramid)

Diverging Stacked Bar Chart (Population Pyramid): Based on an official Vega-Lite example and adapted for use in Deneb within Power BI. Note: Cross-filtering interactivity is limited when using 'aggregate'. Author: Cristobal Salcedo Beltran. Contact: contacto@csalcedodatabi.com.

## El spec

- [`Files/Diverging_Stacked_Bar_Chart_Population_Pyramid.json`](Files/Diverging_Stacked_Bar_Chart_Population_Pyramid.json)

Creado con Deneb `1.7.1.0` sobre `vegaLite` `5.20.1`.

## Cómo usarlo

1. Añade un visual **Deneb** al informe y arrastra los campos que pide el spec.
2. Abre el editor de Deneb y pega el contenido del JSON de arriba.
3. Pulsa **Apply** y ajusta el mapeo de campos si tu modelo usa otros nombres.
