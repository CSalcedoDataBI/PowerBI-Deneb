# Gantt Chart

This Gantt chart template, adapted from Vega-Lite and customized for Deneb in Power BI, provides a clear and functional visualization.
Author: Cristobal Salcedo Beltran. Contact: contacto@csalcedodatabi.com.

## El spec

- [`Gantt_Chart.json`](Gantt_Chart.json)

Creado con Deneb `1.7.1.0` sobre `vegaLite` `5.20.1`.

## Cómo usarlo

1. Añade un visual **Deneb** al informe y arrastra los campos que pide el spec.
2. Abre el editor de Deneb y pega el contenido del JSON de arriba.
3. Pulsa **Apply** y ajusta el mapeo de campos si tu modelo usa otros nombres.
