# Normalized (Percentage) Stacked Bar Chart With Dynamic Labels

Normalized (Percentage) Stacked Bar Chart With Dynamic Labels: Based on an official Vega-Lite example and adapted for use in Deneb within Power BI. Note: Cross-filtering interactivity is limited when using 'aggregate'. Author: Cristobal Salcedo Beltran. Contact: contacto@csalcedodatabi.com.

## El spec

- [`Files/Normalized_Stacked_Bar_Chart_With_Dynamic_Labels.json`](Files/Normalized_Stacked_Bar_Chart_With_Dynamic_Labels.json)

Creado con Deneb `1.7.0.0` sobre `vegaLite` `5.19.0`.

## Cómo usarlo

1. Añade un visual **Deneb** al informe y arrastra los campos que pide el spec.
2. Abre el editor de Deneb y pega el contenido del JSON de arriba.
3. Pulsa **Apply** y ajusta el mapeo de campos si tu modelo usa otros nombres.
